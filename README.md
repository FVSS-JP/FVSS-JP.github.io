# FVSS-JP.github.io

FVSS（形式検証とシステムの安全性保証に関する国際会議）の公式サイトです。

## ページの更新

- 日本語版：`index.md`（公開パス：`/`）
- 英語版：`en/index.md`（公開パス：`/en/`）
- 共通レイアウト・言語切替：`_layouts/bilingual.html`
- サイト全体の設定：`_config.yml`

イベントや委員を変更する場合は、日本語版と英語版の両方を更新してください。
開催年は2026年12月の東京ワークショップ、2027年夏の合宿として掲載しています。
具体的な日程や未定の会場は、決定後に更新してください。

## 第一回合宿のプログラム

第一回合宿のプログラムは `_data/retreat-program.yml` で編集します。
日程・時刻・発表順は日英で共通です。各項目の `ja` に日本語、`en` に英語を記入すると、両ページに反映されます。
片方の言語が空欄の場合は、もう片方の内容を表示します。

現在は3日分の枠を用意しています。`sessions: []` の日は「準備中」と表示されます。
プログラムが決まったら、該当する日の `sessions: []` を次のように置き換えてください。
以下は記入例です。時刻・内容は実際のプログラムに変更してください。

```yaml
days:
  - date: "2027-08-31"
    sessions:
      - start: "13:00"
        end: "13:30"
        title:
          ja: "講演タイトル"
          en: "Talk title"
        speaker:
          ja: "話者名"
          en: "Speaker name"
        affiliation:
          ja: "所属機関"
          en: "Affiliation"
        abstract:
          ja: |
            日本語のアブストラクトを記入します。

            空行で段落を追加できます。
          en: |
            Enter the abstract in English.
      - start: "13:30"
        end: "14:00"
        title:
          ja: "休憩"
          en: "Break"
  - date: "2027-09-01"
    sessions: []
  - date: "2027-09-02"
    sessions: []
```

- 発表枠は `- start:` から始まる項目を追加すると増やせます。記入順に表示します。
- 時刻は `"13:00"` のように引用符で囲みます。開始時刻を省略すると「時刻未定」と表示します。終了時刻も省略できます。
- 話者・所属・アブストラクトは任意です。休憩や昼食などはタイトルと時刻だけで記入できます。
- アブストラクトはクリックすると開きます。本文にはMarkdownを使えます。
- 開催日を変更する場合は、このデータと日英ページの開催概要を更新してください。

表示の枠組みは `_includes/retreat-program.html`、追加のスタイルは `assets/css/retreat-program.css` にあります。

## 公開

既存のGitHub Actionsワークフローが、`main`へのpush時にJekyllでビルドしてGitHub Pagesへ公開します。
ローカルファイルの編集だけでは、公開サイトは更新されません。
