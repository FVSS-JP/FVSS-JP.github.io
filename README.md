# FVSS-JP.github.io

FVSS（形式検証とシステムの安全性保証に関する国際会議）の公式サイトです。

## ページの更新

- 日本語版：`index.md`（公開パス：`/`）
- 英語版：`en/index.md`（公開パス：`/en/`）
- 共通レイアウト・言語切替：`_layouts/bilingual.html`
- サイト全体の設定：`_config.yml`

イベントや委員を変更する場合は、日本語版と英語版の両方を更新してください。
開催年は2026年12月の東京ワークショップ、2027年夏の合宿として掲載しています。
具体的な日程や未定の会場は、決定後に更新してください。

## 公開

既存のGitHub Actionsワークフローが、`main`へのpush時にJekyllでビルドしてGitHub Pagesへ公開します。
ローカルファイルの編集だけでは、公開サイトは更新されません。
